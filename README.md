# ALStudio

ALStudio est une application web responsive d'assistant de mode personnel et de dressing virtuel.

## Démarrage

```bash
npm install
npm run dev
```

- Frontend : `http://localhost:5173`
- API : `http://localhost:3000`

Le projet utilise une structure monorepo légère : `apps/web` pour le frontend et `apps/api` pour l'API.

## Déploiement

Le frontend peut être déployé sur Vercel avec le répertoire racine `apps/web`. L'URL HTTPS du dépôt est :

`https://github.com/Solene-hgs/ALStudio`
